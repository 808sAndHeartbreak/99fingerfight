# 运行美术

当前视觉为暖纸白、深蓝墨色与蓝红阵营色的限色漫画。封面 `public/assets/manga/menu-99.webp` 来自用户于 2026-09-09 提供的替换封面，已压缩为 WebP。主菜单左侧操作、右侧封面和标题；窄屏上图下操作。

背景纸纹、接触爆点、胜利图来自用户提供的躲避球美术资源；两张角色为此前生成的插画。出处清单见 `public/assets/manga/sources.json`，仅记录来源，不构成外部文件依赖。

18 张技能、13 张道具、1 张九标记位于 `public/assets/ink-mono/`，均为黑白透明图标。Three.js 手和动态墨线由代码绘制。兼容手势、盾与音效沿用原游戏导出的 14 个素材，原始出处见 `public/assets/manifest.json`。

Teko 与 Noto Sans SC 本地字体随附 SIL OFL 许可证，必须保留。中文子集缺字时使用系统中文字体回退。原始大图和依赖外部目录的提取脚本不属于此独立项目。
