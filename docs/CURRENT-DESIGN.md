# 当前规则：99 生命、十五种道具与二十种技能（rulesVersion 8）

规则版本 8。37 张黑白漫画图标，角色特写、WebGL 冲击与分段伤害反馈。新手教学使用独立预设，不修改正式玩法。

## 回合与补给

双方初始/上限生命均为 99，双手初始为 1。道具 → 行动 → 对手回合。每回合最多计算一次，计算前后可反复合成并自动使用技能。道具、选招、计算各 20 秒。强欲与肾上腺素是主动结束回合的道具例外；没有合法计算时自动结束。

每位玩家分别在自己的第 1、4、7…回合开始获得一个随机道具，背包上限 3。同名道具可以重复获得。背包已满时补给跳过，不积攒。强欲结束的回合也正常计数。

## 道具

所有道具仅在道具阶段主动使用。手势道具点击后选择任意一方的一只手；其余道具点击后确认发动，目标由规则限定。

| 道具 | 效果与结算 |
|---|---|
| 酒 | 下一次直接技能攻击首段每层 +10，消耗全部酒层数；无期限、可窃取 |
| 肾上腺素 | 立即结束回合；接下来三个己方回合，所有造成伤害 +5、受到伤害 −5；重复延长、可窃取 |
| 增幅 | 任意手 +1，9→0 |
| 退化 | 原逆转；任意手 −1，0→9 |
| 封印 | 手不能发起或成为计算目标，所属玩家回合结束解除；道具仍可改它的数字 |
| 内战 | 目标手减去其拥有者另一只手，负数加 10 |
| 倍增 | 目标手乘以 2，只保留个位 |
| 回响 | 本回合下一次计算只计算一个结果，复制给自己的两只手；另一只被封印也接收复制值 |
| 镜像 | 本回合下一次计算只将结果写入对手目标手，自己的主动手不变 |
| 沉默 | 对手下一回合不能主动用道具，到该回合结束解除；补给和武器补牌正常 |
| 制衡 | 先消耗制衡，双方弃掉剩余道具，分别重抽各自剩余的原数量 |
| 天降的宝札 | 双方补至 3 个，已满的一方不再获得 |
| 强欲 | 先消耗自身，再获得最多 2 个（仍上限 3），立即结束回合，跳过合成与行动 |
| 恩惠 | 自己恢复己方双手数字总和的生命，最多 99，满血或总和为 0 仍消耗 |
| 破坏 | 对手扣除其双手数字总和的生命；不触发或消耗护盾，可致死 |

治疗、毒药已从道具池删除。回响、镜像允许同时存在，重复使用不叠加次数；二者同时存在时，两次触碰沿用同一个结果，仅写入同一只对手目标手。未计算就攻击、强欲或无合法行动结束回合时，效果也失效，不能留到下回合。

## 防御、持续状态与边界

- 普通伤害按 和平 → 55 → 泡沫盾墙 → 单个 5 结算。55 无限免疫普通伤害且不改变数字，双手数字变化后立即失效；合成会将双手归 1，所以也会失去 55 防御。
- 单个 5 减半普通伤害，向上取整，然后该手变为 1。盾墙挡住一段普通伤害消耗一次。前层防御阻挡后不消耗后层，零伤害不消耗任何防御。
- 真实伤害无视且不消耗护盾，但会被和平免疫，肾上腺素的增减伤也有效。认真一拳先将目标双手变为 1、清除盾墙，再造成真实伤害。
- 双枪每发独立结算。指虎对每段直接技能伤害 +10，包含真实伤害，双枪每发变为 15；不增加道具或持续伤害。黯然销魂掌在出手时取已损生命，再加指虎。
- 七伤拳重复施加剩余次数 +7，每次仍为 7；泡沫重复获得次数 +2。指虎永久、可叠层且无上限，玄冥永久且不叠加；七伤与玄冥共存。
- 跳过回合次数累计；跳过整回合操作，补给、持续伤害及状态清理照常。认真一拳跳过自己的下个回合。如来、泰瑟跳过对手下三个回合。被防御挡住普通伤害时，附加效果仍生效。
- 回合开始先计回合并补给，再处理跳过计数、七伤、玄冥、中毒。任一伤害使生命归零时立即结算，不再进行后续伤害、技能附加效果或阶段；双枪致死后停止余下弹数。
- 窃取先保留自身道具，按对手背包顺序填满至 3；对手道具全移走，溢出弃掉。不复制数字。转移和平与肾上腺素剩余回合、指虎与酒层数，合并到自身、对手失去；盾墙、回响、镜像等通用状态与九标记均不转移。之后对手如遇补给回合仍正常抽牌。
- 归一重置双方数字，清除自己的封印、沉默、跳过回合、七伤、玄冥、虚弱、中毒；保留增益、通用状态及双方九标记；第二枚标记直接胜利，不进行下一回合的补给或持续伤害。
- 醉拳攻击次数等概率取 5～10 的整数，逐段结算；虚弱在指虎加成之后，每段 −5、最低 0；随机效果只由确定性规则引擎执行，联机以服务器结果为准。
- 现有道具时限沿用上一轮确认：回响、镜像仅本回合有效且重复使用不叠加；沉默到对手下一回合结束解除。

## 本轮权重与持续计数

- 每种道具独立权重 A:B:C = 4:2:1：A 为倍增、增幅、退化；C 为恩惠、强欲、天降的宝札；其余 B。总权重 33，单件概率分别 4/33、2/33、1/33。所有抽牌来源共用权重。
- 和平立即生效，覆盖双方各自接下来的三个己方回合；施放者当前回合不扣新获得的计数。每个被保护的己方回合结束减一，跳过回合照常；重复延长，不增加强度。窃取到的新和平从自身后续回合计数，已有和平则合并计数。
- 虚弱在拥有者回合结束减一，中毒在回合开始造成普通伤害并减一次；重复施加分别延长五回合。免疫伤害不阻止附加效果、数字重置或九标记强制胜利。

## 酒、肾上腺素与两阶段交互（规则 6）

- 酒与肾上腺素均为 B 级权重 2。道具共 15 种，权重总和 33。
- 酒对下一次直接技能攻击的首段每层 +10，所有层数一次消耗；后续伤害段不加酒。被免疫、护盾挡住或减至 0 仍消耗；无伤害技能、计算、道具及持续伤害不消耗。无回合期限，可窃取。
- 肾上腺素使用后立即结束当前回合，覆盖接下来的三个己方回合。所有伤害来源 +5，所有受到的伤害 −5（含真实伤害、道具及持续伤害），先增减伤、最低 0，再处理护盾。重复获得延长三回合，不叠加强度。可以窃取，归一不清除此增益。
- 顶部只显示「道具—行动」。引擎保留技能选择子步骤，以保证合成许可、指令验证与原有规则不变。
- 无道具、道具用尽或被沉默时，道具阶段停留 1 秒后自动进入行动；本地、教学、服务器共用判断，联机由服务器推进。暂停本地游戏时自动推进也暂停。
- 道具可选目标点击后直接生效，无需选手的道具在槽位旁显示确认按钮；再次点击道具或取消选择可撤回尚未生效的选择。删除 i 按钮，保留悬停与键盘焦点详情。
- 触碰每次 1 秒；回响两次触碰沿用相同算式。顶栏按阵营颜色显示真实 a+b→c；5 的手可悬停查看护盾。历史保留最近 30 条，按回合和行动内容显示。

## 规则 7：连续跳过保护

- 两个相邻己方回合因跳过回合或跳过行动而结束，第二次结算结束后获得坚韧 5 回合，并清除剩余 skip。完整正常行动、放弃合成和无合法目标结束都打断连续计数；封印不计入跳过。
- 坚韧覆盖后续五个己方回合，回合结束减一；免疫认真一拳的下回合跳过、泰瑟枪/如来神掌跳过。强欲和肾上腺素照常获得效果，但不结束当前回合。坚韧不免疫封印、沉默和伤害。
- 坚韧可被窃取，转移剩余回合数；已有坚韧时延长。新获得的坚韧不在获得当回合扣次数，获得时清除剩余跳回合次数及连续计数。
- 每人最多一只手被封印；已有封印的玩家不能再被封印（包括原手），非法目标不消耗道具。到所属玩家回合结束解除。
- 合成仍以 forge / attack 两条权威指令实现；第二条由服务器自动推进，本地和教学也自动执行，不再显示发动按钮。断线恢复时服务器仍继续发动。
- 常驻聚光、顶部色流不锁输入；手部点击热区扩大，空白点击保留所选手。盾改为浅色面与单轮廓，不旋转线框。
