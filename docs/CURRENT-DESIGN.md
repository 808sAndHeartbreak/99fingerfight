# 当前规则：99 生命、十三种道具与十八种技能（rulesVersion 4）

规则版本 4。32 张黑白漫画图标，角色特写、WebGL 冲击与分段伤害反馈。实战教学使用独立预设，不修改正式玩法。

## 回合与补给

双方初始/上限生命均为 99，双手初始为 1。开始 → 规划 → 合成（有配方才进入，可放弃）→ 行动。规划、合成、计算 30 秒，武器攻击 10 秒。强欲是主动结束回合的道具例外；没有合法计算时自动结束。

每位玩家分别在自己的第 1、4、7…回合开始获得一个随机道具，背包上限 3。同名道具可以重复获得。背包已满时补给跳过，不积攒。强欲结束的回合也正常计数。

## 道具

所有道具仅在规划阶段主动使用。手势道具点击后选择任意一方的一只手；其余道具点击后确认发动，目标由规则限定。

| 道具 | 效果与结算 |
|---|---|
| 增幅 | 任意手 +1，9→0 |
| 退化 | 原逆转；任意手 −1，0→9 |
| 封印 | 手不能发起或成为计算目标，所属玩家回合结束解除；道具仍可改它的数字 |
| 内战 | 目标手减去其拥有者另一只手，负数加 10 |
| 倍增 | 目标手乘以 2，只保留个位 |
| 回响 | 本回合下一次计算只计算一个结果，复制给自己的两只手；另一只被封印也接收复制值 |
| 镜像 | 本回合下一次计算只将结果写入对手目标手，自己的主动手不变 |
| 沉默 | 对手下一回合不能主动用道具，到该回合结束解除；补给和武器补牌正常 |
| 制衡 | 先消耗制衡，双方弃掉剩余道具，分别重抽各自剩余的原数量 |
| 天降的宝札 | 双方补至 3 个，已满的一方不再获得 |
| 强欲 | 先消耗自身，再获得最多 2 个（仍上限 3），立即结束回合，跳过合成与行动 |
| 恩惠 | 自己恢复己方双手数字总和的生命，最多 99，满血或总和为 0 仍消耗 |
| 破坏 | 对手扣除其双手数字总和的生命；不触发或消耗护盾，可致死 |

治疗、毒药已从道具池删除。回响、镜像允许同时存在，重复使用不叠加次数；二者同时存在时，两次触碰沿用同一个结果，仅写入同一只对手目标手。未计算就攻击、强欲或无合法行动结束回合时，效果也失效，不能留到下回合。

## 技能

只有合成阶段选择并确认技能，双手先归 1；行动阶段必须发动后结束回合。可放弃合成改为计算。

| 配方 | 技能 | 效果 |
|---|---|---|
| 0+0 | 认真一拳 | 破坏所有护盾，造成 30 点真实伤害；跳过自己下个回合 |
| 0+0 | 醉拳 | 造成 10～40 点随机普通伤害 |
| 0+0 | 七伤拳 | 对手每回合开始受到 7 点真实伤害，持续 7 回合 |
| 2+2 | 剪刀 | 造成 5 点普通伤害，对手双手各减 1（0 变 9） |
| 4+4 | 花蝶扇 | 造成 10 点普通伤害，随机移除对手一个道具 |
| 4+4 | 爪击 | 造成 10 点真实伤害 |
| 5+5 | 如来神掌 | 造成 10 点普通伤害，对手双手归 1，跳过对手下 3 回合 |
| 5+5 | 降龙十八掌 | 造成 50 点普通伤害 |
| 5+5 | 黯然销魂掌 | 造成等于自己已损失生命的普通伤害 |
| 5+5 | 玄冥神掌 | 对手每回合开始受到 5 点真实伤害，永久且不叠加 |
| 6+6 | 碎片手雷 | 造成 30 点普通伤害 |
| 6+6 | 泡沫手雷 | 获得盾墙，完全挡住两次普通伤害；重复获得次数 +2 |
| 6+6 | 指虎 | 永久获得每段直接技能伤害 +10，不叠加 |
| 7+7 | 窃取 | 夺走对手全部道具，最多持有 3 个；复制对手双手数字 |
| 8+8 | 双枪 | 连续 4 次各造成 5 点普通伤害，随后补满自己的道具 |
| 8+8 | 狙击枪 | 造成 30 点真实伤害 |
| 8+8 | 泰瑟枪 | 造成 1 点普通伤害，跳过对手下 3 回合 |
| 9+9 | 归一 | 双方双手归 1，自己获得一枚九；累计两枚立即获胜 |

## 防御、持续状态与边界

- 普通伤害按 55 → 泡沫盾墙 → 单个 5 结算。55 无限免疫普通伤害且不改变数字，双手数字变化后立即失效；合成会将双手归 1，所以也会失去 55 防御。
- 单个 5 减半普通伤害，向上取整，然后该手变为 1。盾墙挡住一段普通伤害消耗一次。前层防御阻挡后不消耗后层，零伤害不消耗任何防御。
- 真实伤害无视且不消耗所有防御。认真一拳例外先将目标所有 5 变为 1、清除盾墙，再造成真实伤害。
- 双枪每发独立结算。指虎对每段直接技能伤害 +10，包含真实伤害，双枪每发变为 15；不增加道具或持续伤害。黯然销魂掌在出手时取已损生命，再加指虎。
- 七伤拳重复施加剩余次数 +7，每次仍为 7；泡沫重复获得次数 +2。指虎、玄冥均永久且不叠加；七伤与玄冥共存。
- 跳过回合次数累计；跳过整回合操作，补给、持续伤害及状态清理照常。认真一拳跳过自己的下个回合。如来、泰瑟跳过对手下三个回合。被防御挡住普通伤害时，附加效果仍生效。
- 回合开始先计回合并补给，再处理跳过计数、七伤、玄冥。任一伤害使生命归零时立即结算，不再进行后续伤害、技能附加效果或阶段；双枪致死后停止余下弹数。
- 窃取先保留自身道具，按对手背包顺序填满至 3；对手道具全移走，溢出弃掉。只复制数字，不复制封印或状态。之后对手如遇补给回合仍正常抽牌。
- 归一只重置数字，保留所有状态和九标记；第二枚标记直接胜利，不进行下一回合的补给或持续伤害。
- 醉拳等概率取 10～40 的整数；随机效果只由确定性规则引擎执行，联机以服务器结果为准。
- 现有道具时限沿用上一轮确认：回响、镜像仅本回合有效且重复使用不叠加；沉默到对手下一回合结束解除。

## 信息展示

- 常驻：99 血条、双方道具名称与数量、补给还有几个己方回合、回响/镜像/沉默、剩余跳过回合、七伤次数、玄冥、盾墙次数、指虎及九标记。
- 悬停/点按：道具完整规则、状态如何解除、补给日程和背包满时的处理。
- 操作时：手势目标数字预览；非手势道具先显示本次实际回血、伤害或补牌数量，再确认消耗。强欲明确说明立即结束回合。
- 变化时：补给集中显示获得的道具名称，背包满显示跳过，战报保留记录。新增道具播放约 1.25 秒起的图标特写及实际结果；计算借用现有触碰表现，回响顺序触碰两次，镜像只更新正确的目标。

## 联机和兼容

本地服务器与本地模式共用规则。hello 必须携带 rulesVersion:4；旧客户端会收到刷新提示。旧存档不直接套用新道具，房间回到准备状态，保留席位与昵称；旧回放明确拒绝。线上使用同一规则版本。

## 试玩候选版本的表现与联机时序

- 技能插画 18 张、道具插画 13 张、九印 1 张；透明 WebP 共约 2.9 MB。游戏加载 public/assets/ink-mono 中的黑白透明图标。
- 技能使用 4 秒起，双枪按实际命中段延长；道具 1.25 秒起；合成 3 秒。首次归一 4.5 秒，九九归一 6.5 秒后再进入胜负页。回合特写 3.2 秒，阶段文字 1.8 秒。均支持减少动态效果与本地暂停。
- 表现只读取权威伤害事件，逐段显示实际伤害、盾墙剩余次数和破盾后的数字；不会在动画中重新随机或结算技能。
- 服务器与客户端共用演出时长。每个动作都预留演出窗口，同阶段道具仅补回演出占用时间，不重新赠送 30 秒规划时间。胜负立即确定，但终结演出不会被服务器提前略过。
- 切后台与重连后以最新快照恢复，不补播过时动作；旧连接回调不能覆盖新连接。规则版本仍为 4，未改变本轮已确认玩法。


## 实战教学
开始游戏中独立进入，三个预设练习演示计算、增幅与剪刀合成、九九归一。预设数值只用于练习，不写入正式对局或联机。每步由玩家操作，无倒计时；误操作提示当前目标，随时可重试本节或退出，完成后返回对战模式选择。所有技能与道具详情仍通过组合图鉴、悬停和 i 查询。


### 试玩版交互修订
主菜单铺满屏幕。回合与技能用有停留的特写；规划／合成／行动的切换仅显示中心文字。倒计时不能点击，动画期间不扣操作时间。未提交的道具可取消；选手优先执行计算，等待服务器期间不打开图鉴。数字查询限制为相关配方，完整图鉴 55 优先，可点击外部关闭。教学计算可选对手任意一只 4，聚光遮罩保留当前目标和退出／取消入口。
