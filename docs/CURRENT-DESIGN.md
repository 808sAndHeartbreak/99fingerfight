# 当前规则：99 生命、十三种道具与二十种技能（rulesVersion 15）

规则版本 15。35 张黑白漫画图标、受击手势击退与分段血量反馈。新手教学使用独立预设，不修改正式玩法。

## 回合与补给

双方初始/上限生命均为 99，双手初始为 1。每回合统一 30 秒，动画播放时暂停计时。道具、手计算和合成没有先后限制；每回合最多计算一次，计算前后可继续用道具、反复合成并自动使用技能。完成计算后点击双手之间的「结束回合」交给对手；未计算时也可手动结束，但优先提示计算；计算后按钮金色脉冲，没有合法操作时加强动态提示，不自动换人。手动或超时结束时，若既未计算也未合成，直接扣 10 HP，可致死且不受护盾或免伤影响；只用道具仍算空过。技能强制跳过和强欲自动结束不罚。强欲与认真一拳保留其立即结束回合的规则。

每位玩家分别在自己的第 1、4、7…回合开始获得一个随机道具，背包上限 3。同名道具可以重复获得。背包已满时补给跳过，不积攒。强欲结束的回合也正常计数。

## 道具

所有道具可在己方回合主动使用，技能演出时不可操作。手势道具点击后选择任意一方的一只手；其余道具点击后确认发动，目标由规则限定。

| 道具 | 效果与结算 |
|---|---|
| 酒 | 下一次直接技能攻击首段每层 +10，消耗全部酒层数；无期限、可窃取 |
| 增幅 | 任意手 +1，9→0 |
| 退化 | 任意手 −1，0→9 |
| 封印 | 手不能发起或成为计算目标，所属玩家回合结束解除；道具仍可改它的数字 |
| 内战 | 目标手减去其拥有者另一只手，负数加 10 |
| 倍增 | 目标手乘以 2，只保留个位 |
| 回响 | 本回合下一次计算只计算一个结果，复制给自己的两只手；另一只被封印也接收复制值 |
| 镜像 | 本回合下一次计算只将结果写入对手目标手，自己的主动手不变 |
| 沉默 | 对手下一回合不能主动用道具，到该回合结束解除；补给和武器补牌正常 |
| 制衡 | 先消耗制衡，双方弃掉剩余道具，分别重抽各自剩余的原数量 |
| 强欲 | 先消耗自身，将自己双手均设为 [1]，再获得最多 2 个（仍上限 3），立即结束回合；坚韧期间不结束，但仍重置双手 |
| 恩惠 | 双方分别回复各自双手数字总和的生命，各自最多 99；满血或总和为 0 仍消耗 |
| 破坏 | 先求双方各自双手总和，再取两个总和之差的绝对值，对对手造成对应真实伤害；不触发或消耗护盾，和平可免疫，可致死 |

回响、镜像允许同时存在，重复使用不叠加次数；二者同时存在时，以最初选中的己方手与对方目标手求和取个位，两次表现沿用同一个结果，写入对方双手；己方不变，被封印的另一只对方手也接受复制值。未计算就结束回合、强欲结束回合时，效果也失效，不能留到下回合。

## 技能

自己的回合中有配方即可选择技能，查看效果并确认后自动释放；确认前可以取消，不消耗数字。全部效果结算后双手归 [1]。合成选项使用完整面板，显示期间隔离背后的手与道具，避免误触；选择「放弃合成」可返回计算或道具操作，数字不会消耗，仍可重新打开合成。计算已用仍可使用道具或合成，完成后手动结束回合。

| 配方 | 技能 | 效果 |
|---|---|---|
| 0+0 | 认真一拳 | 对手双手归 1、清除盾墙，造成 30 点真实伤害；立即结束当前回合，并跳过自己下个回合 |
| 0+0 | 醉拳 | 随机攻击 5～10 次，每次 5 点普通伤害 |
| 0+0 | 七伤拳 | 对手每回合开始受到 7 点真实伤害，持续 7 回合 |
| 2+2 | 剪刀 | 造成 5 点普通伤害，对手双手各减 1（0 变 9） |
| 4+4 | 花蝶扇 | 造成 10 点普通伤害，随机移除对手一个道具 |
| 4+4 | 爪击 | 两次攻击，每次 5 点真实伤害 |
| 4+4 | 和平鸽 | 双方各自接下来 3 回合免疫所有伤害、不耗盾；重复延长 |
| 5+5 | 如来神掌 | 造成 10 点普通伤害，对手双手归 1，跳过对手下 3 回合 |
| 5+5 | 降龙十八掌 | 造成 50 点普通伤害 |
| 5+5 | 黯然销魂掌 | 造成等于自己已损失生命的普通伤害 |
| 5+5 | 玄冥神掌 | 对手每回合开始受到 5 点真实伤害，永久且不叠加 |
| 6+6 | 碎片手雷 | 造成 30 点普通伤害 |
| 6+6 | 泡沫手雷 | 获得盾墙，完全挡住两次普通伤害；重复获得次数 +2 |
| 6+6 | 指虎 | 永久获得每段直接技能伤害 +10，可叠加 |

| 8+8 | 狙击枪 | 造成 30 点真实伤害 |
| 8+8 | 泰瑟枪 | 造成 1 点普通伤害，跳过对手下 3 回合 |
| 9+9 | 归一 | 双方双手归 1，清除自己的全部减益，获得一次归一标记；累计使用两次立即获胜 |

## 防御、持续状态与边界

- 普通伤害按 和平 → 55 → 泡沫盾墙 → 单个 5 结算。55 无限免疫普通伤害且不改变数字，双手数字变化后立即失效；合成会将双手归 1，所以也会失去 55 防御。
- 单个 5 减半普通伤害，向上取整，然后该手变为 1。盾墙挡住一段普通伤害消耗一次。前层防御阻挡后不消耗后层，零伤害不消耗任何防御。
- 真实伤害无视且不消耗护盾，但会被和平免疫。认真一拳先将目标双手变为 1、清除盾墙，再造成真实伤害。
- 双枪每发独立结算。指虎对每段直接技能伤害 +10，包含真实伤害，双枪每发变为 15；不增加道具或持续伤害。黯然销魂掌在出手时取已损生命，再加指虎。
- 七伤拳重复施加剩余次数 +7，每次仍为 7；泡沫重复获得次数 +2。指虎永久、可叠层且无上限，玄冥永久且不叠加；七伤与玄冥共存。
- 跳过回合次数累计；跳过整回合操作，补给、持续伤害及状态清理照常。认真一拳跳过自己的下个回合。如来、泰瑟跳过对手下三个回合。被防御挡住普通伤害时，附加效果仍生效。
- 回合开始先计回合并补给，再处理跳过计数、七伤、玄冥、中毒。任一伤害使生命归零时立即结算，不再进行后续伤害、技能附加效果；双枪致死后停止余下弹数。
- 窃取先保留自身道具，按对手背包顺序填满至 3；对手道具全移走，溢出弃掉。不复制数字。转移和平与坚韧剩余回合、指虎与酒层数，合并到自身、对手失去；盾墙、回响、镜像等通用状态与归一标记均不转移。之后对手如遇补给回合仍正常抽牌。
- 归一重置双方数字，清除自己的封印、沉默、跳过回合、七伤、玄冥、虚弱、中毒；保留增益、通用状态及双方归一标记；第二次归一直接胜利，不进行下一回合的补给或持续伤害。
- 醉拳攻击次数等概率取 5～10 的整数，逐段结算；虚弱在指虎加成之后，每段 −5、最低 0；随机效果只由确定性规则引擎执行，联机以服务器结果为准。
- 道具时限：回响、镜像仅本回合有效且重复使用不叠加；沉默到对手下一回合结束解除。

## 信息展示

- 常驻：99 血条、双方道具名称与数量、补给还有几个己方回合、回响/镜像/沉默、剩余跳过回合、七伤次数、玄冥、盾墙次数、指虎层数、和平回合、虚弱回合、中毒次数及归一标记。
- 悬停/点按：道具完整规则、状态如何解除、补给日程和背包满时的处理。
- 操作时：手势目标数字预览；非手势道具先显示本次实际回血、伤害或补牌数量，再确认消耗。强欲明确说明立即结束回合。
- 变化时：补给集中显示获得的道具名称，背包满显示跳过，历史保留记录。道具离槽 250 ms、中心聚焦 350 ms、飞向目标 300 ms，随后 800 ms 完成反馈；播报另留 6 秒，排队等待不消耗阅读时间；变化在手部、血条、状态或道具区显示前后值；计算借用现有触碰表现，回响顺序触碰两次，镜像只更新正确的目标。

## 联机和兼容

本地服务器与本地模式共用规则。hello 必须携带 protocolVersion:2 和 rulesVersion:15；旧客户端会收到刷新提示。旧存档不直接套用新道具，房间回到准备状态，保留席位与昵称；旧回放明确拒绝。旧版客户端刷新后进入新规则。

## 当前界面与教学

- 姓名、HP 与中央固定计时框位于顶部，状态排列在双方外侧。常态白底大数字，10 秒起黄底，5 秒起闪烁；交接时数字换为框内箭头，玩家底色与半场聚光同步切换。先完成交接，再显示本回合补给。
- 手部整手可点，悬停与选中表现区分；行动手轻微浮动，关节使用灰色阴影。受伤击退 450 ms，HP 和护盾碎裂同步反馈。
- 底部包含记录、菜单，以及技能配方 / 道具大全翻页。配方显示数字；详情才显示图标、名称与效果。仅单手 [5] 护盾保留防御规则折叠；道具细节可展开。两页高度相同。
- 信息详情按屏幕扩展，播报按空间排队，消散后平滑补位；等待的卡片暂停阅读计时。记录保留最近 120 条，可复制导出。
- 教学有两节：连续攻防与两次归一。第一节从己方 [3]/[6]、对方 [1]/[1] 开始，依次计算、结束回合、对方形成护盾、获得并使用增幅、凑齐 [6]/[6]、手雷攻击。第二节明确转场，演示两次归一；完成后进入完成教学页。
- 归一标记永久保留，无法清除或转移。第二次太极演出直接衔接胜利页；结果页提供再来一局、记录和返回菜单。联机再战在原房间等待双方同意。
- BGM 默认 30%，尊重保存的用户音量。运行音轨为 pixel-afternoon-streets-seamless.mp3；手势后立即播放，解码后接入无缝缓冲循环。
- 本地 ESC 打开暂停菜单；联机菜单、图鉴和后台不暂停服务器时间。全屏优先，小尺寸和移动设备以横屏为目标。
