# 当前规则：99 生命、十五种道具与二十种技能（rulesVersion 12）

规则版本 12。37 张黑白漫画图标，角色特写、受击手势击退与分段血量反馈。新手教学使用独立预设，不修改正式玩法。

## 回合与补给

双方初始/上限生命均为 99，双手初始为 1。每回合统一 30 秒，动画播放时暂停计时。道具、手计算和合成没有先后限制；每回合最多计算一次，计算前后可继续用道具、反复合成并自动使用技能。完成计算后点击倒计时旁的「结束回合」交给对手；未计算且有合法计算目标时，不能手动结束；计算后按钮金色脉冲，没有合法操作时加强动态提示，不自动换人。超时直接结束回合。强欲、肾上腺素与认真一拳保留其立即结束回合的规则。

每位玩家分别在自己的第 1、4、7…回合开始获得一个随机道具，背包上限 3。同名道具可以重复获得。背包已满时补给跳过，不积攒。强欲结束的回合也正常计数。

## 道具

所有道具可在己方回合主动使用，技能演出时不可操作。手势道具点击后选择任意一方的一只手；其余道具点击后确认发动，目标由规则限定。

| 道具 | 效果与结算 |
|---|---|
| 酒 | 下一次直接技能攻击首段每层 +10，消耗全部酒层数；无期限、可窃取 |
| 肾上腺素 | 立即结束回合；接下来三个己方回合，所有造成伤害 +5、受到伤害 −5；重复延长、可窃取 |
| 增幅 | 任意手 +1，9→0 |
| 退化 | 原逆转；任意手 −1，0→9 |
| 封印 | 手不能发起或成为计算目标，所属玩家回合结束解除；道具仍可改它的数字 |
| 内战 | 目标手减去其拥有者另一只手，负数加 10 |
| 倍增 | 目标手乘以 2，只保留个位 |
| 回响 | 本回合下一次计算只计算一个结果，复制给自己的两只手；另一只被封印也接收复制值 |
| 镜像 | 本回合下一次计算只将结果写入对手目标手，自己的主动手不变 |
| 沉默 | 对手下一回合不能主动用道具，到该回合结束解除；补给和武器补牌正常 |
| 制衡 | 先消耗制衡，双方弃掉剩余道具，分别重抽各自剩余的原数量 |
| 天降的宝札 | 双方补至 3 个，已满的一方不再获得 |
| 强欲 | 先消耗自身，再获得最多 2 个（仍上限 3），立即结束回合，跳过合成与行动 |
| 恩惠 | 自己恢复己方双手数字总和的生命，最多 99，满血或总和为 0 仍消耗 |
| 破坏 | 对手扣除其双手数字总和的生命；不触发或消耗护盾，可致死 |

治疗、毒药已从道具池删除。回响、镜像允许同时存在，重复使用不叠加次数；二者同时存在时，以最初选中的己方手与对方目标手求和取个位，两次表现沿用同一个结果，写入对方双手；己方不变，被封印的另一只对方手也接受复制值。未计算就结束回合、强欲结束回合时，效果也失效，不能留到下回合。

## 技能

自己的回合中有配方即可选择技能，自动释放，全部效果结算后双手归 [1]。合成选项不占用独立阶段、不遮挡双手及道具，可以直接改用道具或计算，无需放弃组合。计算已用仍可使用道具或合成，完成后手动结束回合。

| 配方 | 技能 | 效果 |
|---|---|---|
| 0+0 | 认真一拳 | 对手双手归 1、清除盾墙，造成 30 点真实伤害；立即结束当前回合，并跳过自己下个回合 |
| 0+0 | 醉拳 | 随机攻击 5～10 次，每次 5 点普通伤害 |
| 0+0 | 七伤拳 | 对手每回合开始受到 7 点真实伤害，持续 7 回合 |
| 2+2 | 剪刀 | 造成 5 点普通伤害，对手双手各减 1（0 变 9） |
| 4+4 | 花蝶扇 | 造成 10 点普通伤害，随机移除对手一个道具 |
| 4+4 | 爪击 | 两次攻击，每次 5 点真实伤害 |
| 4+4 | 和平鸽 | 双方各自接下来 3 回合免疫所有伤害、不耗盾；重复延长 |
| 5+5 | 如来神掌 | 造成 10 点普通伤害，对手双手归 1，跳过对手下 3 回合 |
| 5+5 | 降龙十八掌 | 造成 50 点普通伤害 |
| 5+5 | 黯然销魂掌 | 造成等于自己已损失生命的普通伤害 |
| 5+5 | 玄冥神掌 | 对手每回合开始受到 5 点真实伤害，永久且不叠加 |
| 6+6 | 碎片手雷 | 造成 30 点普通伤害 |
| 6+6 | 泡沫手雷 | 获得盾墙，完全挡住两次普通伤害；重复获得次数 +2 |
| 6+6 | 指虎 | 永久获得每段直接技能伤害 +10，可叠加 |
| 7+7 | 窃取 | 夺走对手全部道具及和平、指虎、酒、肾上腺素；道具最多持有 3 个 |
| 7+7 | 双头蛇 | 对手虚弱、中毒 5 回合：每段直接技能伤害 −5（最低 0），每回合开始受到 2 点普通伤害 |
| 8+8 | 双枪 | 连续 4 次各造成 5 点普通伤害，随后补满自己的道具 |
| 8+8 | 狙击枪 | 造成 30 点真实伤害 |
| 8+8 | 泰瑟枪 | 造成 1 点普通伤害，跳过对手下 3 回合 |
| 9+9 | 归一 | 双方双手归 1，清除自己的全部减益，获得一枚九；累计两枚立即获胜 |

## 防御、持续状态与边界

- 普通伤害按 和平 → 55 → 泡沫盾墙 → 单个 5 结算。55 无限免疫普通伤害且不改变数字，双手数字变化后立即失效；合成会将双手归 1，所以也会失去 55 防御。
- 单个 5 减半普通伤害，向上取整，然后该手变为 1。盾墙挡住一段普通伤害消耗一次。前层防御阻挡后不消耗后层，零伤害不消耗任何防御。
- 真实伤害无视且不消耗护盾，但会被和平免疫，肾上腺素的增减伤也有效。认真一拳先将目标双手变为 1、清除盾墙，再造成真实伤害。
- 双枪每发独立结算。指虎对每段直接技能伤害 +10，包含真实伤害，双枪每发变为 15；不增加道具或持续伤害。黯然销魂掌在出手时取已损生命，再加指虎。
- 七伤拳重复施加剩余次数 +7，每次仍为 7；泡沫重复获得次数 +2。指虎永久、可叠层且无上限，玄冥永久且不叠加；七伤与玄冥共存。
- 跳过回合次数累计；跳过整回合操作，补给、持续伤害及状态清理照常。认真一拳跳过自己的下个回合。如来、泰瑟跳过对手下三个回合。被防御挡住普通伤害时，附加效果仍生效。
- 回合开始先计回合并补给，再处理跳过计数、七伤、玄冥、中毒。任一伤害使生命归零时立即结算，不再进行后续伤害、技能附加效果；双枪致死后停止余下弹数。
- 窃取先保留自身道具，按对手背包顺序填满至 3；对手道具全移走，溢出弃掉。不复制数字。转移和平与肾上腺素剩余回合、指虎与酒层数，合并到自身、对手失去；盾墙、回响、镜像等通用状态与九标记均不转移。之后对手如遇补给回合仍正常抽牌。
- 归一重置双方数字，清除自己的封印、沉默、跳过回合、七伤、玄冥、虚弱、中毒；保留增益、通用状态及双方九标记；第二枚标记直接胜利，不进行下一回合的补给或持续伤害。
- 醉拳攻击次数等概率取 5～10 的整数，逐段结算；虚弱在指虎加成之后，每段 −5、最低 0；随机效果只由确定性规则引擎执行，联机以服务器结果为准。
- 现有道具时限沿用上一轮确认：回响、镜像仅本回合有效且重复使用不叠加；沉默到对手下一回合结束解除。

## 信息展示

- 常驻：99 血条、双方道具名称与数量、补给还有几个己方回合、回响/镜像/沉默、剩余跳过回合、七伤次数、玄冥、盾墙次数、指虎层数、和平回合、虚弱回合、中毒次数及九标记。
- 悬停/点按：道具完整规则、状态如何解除、补给日程和背包满时的处理。
- 操作时：手势目标数字预览；非手势道具先显示本次实际回血、伤害或补牌数量，再确认消耗。强欲明确说明立即结束回合。
- 变化时：补给集中显示获得的道具名称，背包满显示跳过，历史保留记录。道具离槽、中心说明、飞向目标及消失共 2.6 秒；变化在手部、血条、状态或道具区显示前后值；计算借用现有触碰表现，回响顺序触碰两次，镜像只更新正确的目标。

## 统一回合交互（2026-09-11）

- 顶部只保留回合归属、放大的倒计时、结束回合按钮和一句动态操作提示。选手后说明计算结果归属；镜像、回响使用对应提示，不显示下方备注小字。
- 每位玩家仍有三个道具位，采用有凹槽层次的托盘；使用、选中、不可用状态区分。战场静止时为干净纸色，斜线、彩带和网点从常驻背景中移除，冲击表现只在出手时出现。
- 每回合共享 30 秒，演出只暂停计时，不重置额度。前端保留毫秒精度，服务器用 readyAt/deadlineAt 统一计时。技能在 readyAt 自动释放；开始和超时由服务器处理，超时不替玩家消耗道具。
- 教学无倒计时（显示练习标识）。加和后新增「数字组合能合成不同技能」说明，指向下方图鉴，并实际练习结束回合。原五节教学同步移除进入行动步骤。
- 补给与状态结算仍在回合开始自动执行；内部 start 仅代表自动结算，action 代表统一可操作回合，不存在 planning/synthesis 阶段。
- 规则版本升为 9，协议仍为 2。旧客户端需刷新；旧联机对局回到准备状态并保留房间与身份。旧人机存档与回放明确拒绝，不套用新规则。

## 抽牌权重与跳过保护

每种道具独立权重 A:B:C = 4:2:1：倍增、增幅、退化为 A；恩惠、强欲、天降的宝札为 C；其余为 B。总权重 33，所有抽牌共用此规则。

连续两次未能行动后获得坚韧，后续五个己方回合免疫跳过。正常结束回合不增加连续跳过计数；强欲和肾上腺素在无坚韧时算跳过行动，坚韧期间不强制结束回合。坚韧可被窃取，归一保留。

镜像、回响只影响本回合计算；计算完成后暂不可使用，保留至下回合。

## 规则 11：事件反馈与 AI

- 常规技能使用战场内横幅，血条持续可见；九印和胜负保留重点演出。伤害逐段更新，血量数字连续变化，保留损失尾条与前后值。
- 道具图标从原槽位飞向说明横幅，停留后飞向目标消失；650ms 合成反馈展示双手归 1，再自动释放技能。持续伤害逐项展示，不再被换人瞬间略过。
- 所有阻塞演出时长由客户端与服务端共用，倒计时显示暂停。状态/道具的附着反馈在演出内完成，不再叠加旧补给通知动画。
- 已计算或发动技能后使用强欲/肾上腺素，仍立即结束回合，但不再误记为整回合未行动，不可据此累积坚韧。
- PVE 开局先选简单、进阶、大师。简单采用容易遗漏组合的局部选择；进阶看短线后续；大师搜索同回合连招与对手应对。搜索使用假设随机样本，不读取真实随机流，通过 Worker 避免阻塞 UI。
- 新 PVE 存档保留难度和剩余时间，拒绝旧规则存档。菜单/重开取消旧 AI 请求，防止迟到决策落到新对局。
- 音效按出场、道具生效、治疗、防御、回合和技能类型区分；音效滑杆为 0 时不创建发声节点。

## 规则 11 教学与表现

- 合成只记录待释放技能，暂时保留配方数字；服务器自动释放，所有技能效果（包括致胜）结算后才归 [1]。演出同步先显示目标变化，再显示自己归 [1]。
- 回合交接展示 1.2 秒行动方横幅，结束后开放操作；对手在回合外形成配方，下个可行动回合显示合成选择。
- 第一章必须查看 [2] + [2] 图鉴，才解锁结束回合。道具、图鉴等浮窗位于教学遮罩之上。第三章只练习护盾攻击；第五章从 [8] / [9] 碰对手 [1] / [1] 起步。
- 道具演出 3.8 秒；普通技能 3.65 秒起，按事件数量增加。通知保留 4.4 秒并纵向排列；伤害使用受击方手部击退、血量变化与护盾消散，不使用伤害斜线。
- 规则 10 及以前 PVE 存档拒绝恢复；旧在线对局回到等待状态，保留房间与身份，可重新准备。

## 规则 12 操作引导

- `canEndTurn` 统一约束手动结束：完成计算，或确实无合法计算目标。本地会话与联机请求入口都校验；AI 候选指令也遵循相同规则。纯 reducer 的 end 仍用于可信时钟超时、模拟和存档回放，超时不必替玩家计算。
- 未计算时可操作手的光环与数字呼吸发光；计算后按钮金色强调，无操作时加强脉冲。保留强欲、肾上腺素、认真一拳的自动结束效果。
- 教学入口按钮与内容同宽。ESC 可在选择或动画中打开暂停面板，支持继续、重试、退出；暂停不重置当前教学步骤。
