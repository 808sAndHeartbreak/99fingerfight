# 玩家试玩指引

地址：https://fingerfight.run.ingarena.net/

新玩家先选择「开始游戏 → 游戏教学」。完成三个练习后选择本地或联机。好友对战由一人创建房间、复制邀请，另一人打开链接或输入六位房间码，双方准备后开始。快速匹配直接开局。

联机菜单不暂停计时。刷新当前标签页可恢复；确认断线后席位最多保留 60 秒。主动退出进行中的对局会判负。

反馈时请记录设备、浏览器、操作、双方数字和道具、房间码及大致时间。公司外访问范围取决于 RUN 平台策略。当前未做真实手机触屏、大规模并发与公网弱网验证。


## 节奏评估基线（2026-09-08）
按当前 chooseCommand、种子 1～100 进行 AI 自战：全部结束；单方回合数最少 18、中位 53、90 分位 74、最长 135；14 场以九九归一结束。按当前 presentationDuration 累计的动画预算中位约 9.2 分钟，不含思考、网络和服务器交接余量，并非真人实测时长。AI 使用了 9 种技能，受其估值策略影响，不能据此判定另外 9 种对真人没有价值。
复玩具有数字组合、道具反制与双胜利条件的基础，但长对局、重复演出和跳回合期间的等待需优先收集真人反馈。暂保留已确认的慢速演出；是否采用首次完整／重复精简或调整控制技能，应经产品确认后再改规则或演出时长。
