# 玩家试玩指引

地址：https://fingerfight.run.ingarena.net/

新玩家先选择「开始游戏 → 游戏教学」。完成三个练习后选择本地或联机。好友对战由一人创建房间、复制邀请，另一人打开链接或输入六位房间码，双方准备后开始。快速匹配直接开局。

联机菜单不暂停计时。刷新当前标签页可恢复；确认断线后席位最多保留 60 秒。主动退出进行中的对局会判负。

反馈时请记录设备、浏览器、操作、双方数字和道具、房间码及大致时间。公司外访问范围取决于 RUN 平台策略。当前未做真实手机触屏、大规模并发与公网弱网验证。


## 试玩关注点
当前版本已缩短重复演出，旧版动画时长估算不再适用。请重点反馈阶段切换是否及时、道具是否容易找到、常驻图鉴是否易读。100 局 AI 回归用于规则稳定性，不能替代真人玩法平衡验证。
